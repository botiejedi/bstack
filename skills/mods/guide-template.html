Plugin Field Guide

Five plugins you just added. Three run on their own once they're installed. Two only do something when you ask. This page shows when each one fires and what to type.

Start here: about 3 minutes

  1. Restart Claude Code. Plugins load at startup, so the session they were installed from can't see them yet.
  2. In your main project, type recommend automations for this project. That runs claude-code-setup and shows you what else is worth adding.
  3. The next time you correct Claude for the same thing twice, type /hookify.

How to use each one

context7

automatic · MCP

Fetches current, version-specific docs for a library, so Claude stops guessing at APIs from old training data.

Use it when
  • You ask how to use a crate, framework or SDK
  • The library had a major release recently
  • Claude's code calls a function that doesn't exist
Type this
use context7: show the axum 0.8 Router API
use context7 to check the current clap derive syntax
You'll see

Claude calls resolve-library-id, then query-docs, and answers from what comes back.

Watch out

Without a key it shares an anonymous rate limit. For your own quota, set CONTEXT7_API_KEY and restart. It covers public libraries, not your private configs.

rust-analyzer-lsp

automatic · .rs files

Gives Claude the same code intelligence your editor has: go to definition, find references, and compiler errors right after an edit.

Use it when
  • You work in any Cargo project
  • You're refactoring and need every caller
  • You want type errors caught before cargo build
Type this
find every caller of parse_config and rename it
what type does this function return?
You'll see

Claude looks up symbols through the language server instead of grepping, and fixes type errors before it reports the work as done.

Watch out

Done already: the rust-analyzer component is installed through rustup (1.94.0). It needs a Cargo.toml, and indexing a large project the first time takes a minute. It does nothing in a non-Rust folder.

hookify

you create · then automatic

Turns "stop doing that" into a rule that warns or blocks. You write it in plain words, and it takes effect on the next tool call with no restart.

Use it when
  • You've corrected the same behaviour twice
  • A command is too risky to leave to memory
  • You want a reminder at the end of each turn
Type this
/hookify Block pct destroy and zfs destroy
/hookify
/hookify:list
/hookify:configure
You'll see

A rule file at .claude/hookify.<name>.local.md. Bare /hookify scans the conversation for your corrections and suggests rules. Each rule has an event (bash, file, stop, prompt) and an action (warn or block).

Watch out

Rules belong to one project. If the project's .gitignore doesn't exclude them, they get committed and reach every clone.

security-guidance

automatic · 3 layers

Reviews code Claude writes for injection, XSS, SSRF, hardcoded secrets, unsafe deserialization and path traversal.

Layers
  • Pattern warning on every edit, about 25 regexes, free
  • Diff review when a turn ends, sent to Opus
  • Deep review on git commit, which traces data flow across files
Add your own rules

Create ~/.claude/claude-security-guidance.md and list rules in plain words. For example: "Credential values never go in a tracked note."

You'll see

Claude sometimes fixes a finding before it replies. That means layer 2 caught something.

Watch out

Layers 2 and 3 send diffs to Anthropic and use your plan's usage on every turn that changes code. If several agents share one worktree, set ENABLE_STOP_REVIEW=0. To turn the whole plugin off, set SECURITY_GUIDANCE_DISABLE=1.

claude-code-setup

on request · read-only

Scans a project and recommends the top one or two automations in each category: MCP servers, skills, hooks, subagents and slash commands.

Use it when
  • You start a new repo
  • Once per existing project, to find gaps
  • Before you hand-write another hook
Type this
recommend automations for this project
what hooks should I use?
You'll see

A short ranked list for each category, with the reason behind each pick.

Watch out

It only recommends and never changes anything. You decide what to install. Some picks may duplicate what you already have.

All five come from claude-plugins-official and are installed at user scope. Install counts used to choose them came from the plugin catalog snapshot of July 2026.

To remove one, run claude plugin uninstall <name>@claude-plugins-official.
